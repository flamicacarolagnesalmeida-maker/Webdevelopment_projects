# Web Development Projects

A collection of beginner-friendly web development projects created to practice and strengthen my understanding of web development.

The main focus of this folder is **backend development**, with some frontend projects and full-stack applications along the way.

## 📁 What This Folder Contains

The projects are designed to gradually build familiarity with:

* HTML, CSS and basic JavaScript
* Node.js
* Express.js
* REST APIs
* HTTP requests and responses
* Databases and SQL
* MySQL
* Database connectivity
* Authentication and authorization
* Middleware
* CRUD operations
* API testing with Postman
* Frontend-backend communication
* Basic full-stack development

## 🎯 Goal

The goal of these projects is **practice and learning** rather than building production-ready applications.

Each project is an opportunity to understand a particular concept, experiment with different approaches, and become more comfortable building web applications from scratch.

## 🗂️ Projects

Projects will be added progressively as I learn and practice different web development concepts.

Each project may contain its own README explaining:

* What the project does
* Technologies used
* Concepts practiced
* How to run it
* What I learned

## 🛠️ Technologies

The technologies used will vary between projects, but the main focus will be on:

**Frontend**

* HTML
* CSS
* JavaScript

**Backend**

* Node.js
* Express.js

**Database**

* MySQL
* SQL
* Database libraries/ORMs

**Tools**

* Git & GitHub
* npm
* Postman

## 📌 Note

This is a **learning repository**. The projects may range from very simple exercises to more involved backend and full-stack applications as my skills develop.

The purpose is to learn by building, making mistakes, and improving with each project.
